avanza a la siguiente sin validación.

## Diferido (arquitectura preparada, no implementado)

- **ARCA real** (`ArcaInvoiceProvider`: certificados, clave privada cifrada, WSAA/WSFE, CAE real).
- **WhatsApp**: módulo `channels/whatsapp`, webhook, bot engine, correlación de conversación.
- **Jobs asíncronos** (Redis + BullMQ): emails, PDFs, reintentos ARCA, reportes.
- **Webhooks** `/webhooks/whatsapp`, `/webhooks/payments` (firma, dedupe, idempotencia).
- **Módulo `ai`**: interpretación de mensajes, extracción de CUIT, intención — solo vía tools validadas, nunca acciones fiscales directas.
- **Pagos completos**, reportes avanzados, app móvil, OAuth, StorageProvider S3/R2, EmailProvider real, observabilidad (Sentry/OTel/Datadog).

En el MVP estos existen como **interfaces + implementación mock/in-process** detrás de abstracciones.

## Criterio de "Fase 8 terminada"

```bash
pnpm install
docker compose -f infra/docker-compose.yml --env-file .env up -d
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Con la cuenta demo: entrar → ver dashboard → crear cliente → crear producto →
crear factura → ver factura → autorizarla con `MockInvoiceProvider` → ver el
dashboard actualizado. Swagger operativo. Tests básicos en verde.
